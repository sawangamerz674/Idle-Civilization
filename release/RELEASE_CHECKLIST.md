# Idle Civilization 1.0.0 - release checklist

## What is in the build
- Plain static files: open `index.html` through any web server (no build step). All art and all sound are generated by the game itself, so there are no third-party assets or licences to track.
- The CrazyGames SDK v3 script tag is in `index.html` (official SDK only). The game also runs without it.

## Before uploading to CrazyGames (check each against the CURRENT CrazyGames developer documentation)
- [ ] Zip the game folder so that `index.html` is at the root of the zip (zip the *contents*, not the parent folder). Remove `release/` from the upload zip if you do not want to ship it.
- [ ] Test in the CrazyGames QA tool / preview with the SDK `environment` = `local` and `crazygames`.
- [ ] Rewarded ads: only requested after the player clicks a button (HUD gift button, "Double it" in the Welcome back dialog). Game loop pauses and audio mutes while an ad plays; both resume afterwards.
- [ ] Confirm gameplay start/stop usage matches the current guidelines (`gameplayStart` is called once the game is ready).
- [ ] Confirm the size limits (initial download size, file count) in the current docs. The game is about 0.5 MB without the store images.
- [ ] Cover images are in `release/store/` (1920x1080, 800x1200, 800x800). Check the exact sizes and formats the submission form currently asks for and resize if needed.
- [ ] Title, short description and tags are yours to write; suggested description: "Grow a tiny Stone Age village into a futuristic empire. Build, research, advance through five eras and start again with Civilization Legacy."
- [ ] No external links, no external requests other than the SDK script (the game makes none).
- [ ] Desktop and mobile browsers: portrait phone, landscape phone, desktop. Mobile layout verified at 390x844, 844x390 and 1920x1080.

## Manual QA pass (about 10 minutes)
1. New game: build a farm, woodcutter, stone collector and hut; check resources grow and the HUD updates.
2. Advance to Ancient Age (needs Basic Tools research); check the background, music theme and buildings change.
3. Settings: toggle music/effects, move the volume sliders, use the HUD speaker button.
4. Save now, reload the page: progress is restored. Export the save, delete it, import it again.
5. Leave the tab hidden for a minute: the Welcome back dialog shows offline gains.
6. Open Legacy: the Ascend button stays disabled until a point can be earned.
7. With the SDK present: the gift button appears; watch a rewarded ad; a boost badge shows in the HUD.
8. Phone: drag the scene sideways; open every panel and check nothing is cut off.

## Known limits
- The generative music is intentionally simple and quiet; replace it by adding audio files under `assets/audio/` and loading them in `js/core/AudioManager.js` if you want recorded tracks.
- Cloud save uses the SDK data module only when the SDK environment allows it; otherwise the browser's storage is used.
